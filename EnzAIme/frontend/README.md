# ENZAIme frontend

React + Vite UI for the ENZAIme backend API.

```bash
npm install
cp .env.example .env   # VITE_API_BASE_URL defaults to http://localhost:8000
npm run dev
```

Production build: `npm run build` (outputs `dist/`). See the root `README.md` and
`docs/deployment.md` for full instructions.
